Font Size

文字サイズ（階調スケール）。基準となる本文から、注釈、ヒーロー見出しまでの役割スケールです。

Font Weight

文字の太さ。同じサイズでも骨格のウェイトにより適切な強弱と視線をコントロールします。

Line Height

行間・余白の密度。見出し向きの引き締められた配置と、快適に読み進めるための贅沢な長文余白を提供します。

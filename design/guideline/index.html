Typography

Font Size (Static)

文字サイズ（固定階調スケール）。バッジやUIコントロールなど、スクリーンの大きさによらず一定のサイジングを求める基準・レイアウト向けのスケールです。

Fluid Typography & Character Capacity (流動・文字数保証スケール)

スクリーンの大きさに呼応して滑らかに可変し、正味80vw描画領域に対して「1行約20文字・30文字」の最適な文字密度を維持する知的可変タイポグラフィ群です。（ウィンドウ幅を変えると自動で伸縮します）

Font Weight

文字の太さ。同じサイズでも骨格のウェイトにより適切な強弱と視線をコントロールします。

Line Height

行間・余白の密度。見出し向きの引き締められた配置と、快適に読み進めるための贅沢な長文余白を提供します。

Spacing & Layout Architecture

Hybrid Space Scale

「静的4pxグリッド」と「錯視補正 (Micro)」の厳密性、文字に呼吸同調する「em比例 (Proportional)」、そして画面幅で開放感を変える「Fluidセクションスケール」を融合した全領域対応の間取り戦略です。

Static Scale & Micro Optical Adjuster

厳密なレイアウトを支える王道の4pxグリッド（1〜32）と、アイコンや線画の軸補正専用の 1px, 2px, 3px 錯視オフセットスケールです。

Proportional Scale (Font-Synchronized Space)

単位に em を採用し、隣合う文字（親フォントサイズ）の伸び縮みに完全にシンクロして広がりや詰めをキープするインテリジェントな文字比例余白です。

Fluid Macro Scale (Viewport-Responsive Sepration)

スマホ等での過剰な無駄余白を除去し、PCワイド画面では豪快に余白を開放する clamp() クラスの大空間セクション・コンテナスケールです。

Special Keyword (Platform-Transparent Auto Spacer)

Web CSSでは auto、モバイルアプリ(iOS/Android) 変換時には Spacer() や Modifier.weight(1f) に該当する余白充填シンボルです。
